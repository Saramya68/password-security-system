# password-security-system
🔐 Digital Lock System (Password-Based)
📌 Overview

This project implements a password-based digital lock system using digital logic concepts. The system verifies a user-entered password with a predefined stored password and grants or denies access accordingly.

⚙️ Features

🔑 Secure password verification using XOR/XNOR logic

✅ Access granted (LED ON) for correct password

❌ Access denied for incorrect password

⚡ Real-time input validation

🧠 Based on combinational and sequential logic circuits

🧰 Components Used

Logic Gates (XOR/XNOR, AND, NOT)

Flip-Flops (for state/storage)

Input switches (for password entry)

LEDs (for output indication)

Power supply

🧠 Working Principle

The entered password is given through input switches.

Each bit is compared with the stored password using XOR/XNOR logic.

If all bits match, the AND gate outputs HIGH → Unlock (LED ON)

If any bit mismatches, output remains LOW → Access Denied
